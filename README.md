# Smallest "Hello, World!\n" Program

This program is 60 bytes.

To my knowledge, the previous known record was [63
bytes](https://www.muppetlabs.com/~breadbox/software/tiny/hello.asm.txt)
(accounting for using the same variation of "Hello, World!\n") held by Brian
Raiter.

See more details [here](https://youtu.be/BdMkqouFbBw).
